## Reproduce

```bash
OUT=$PWD/.logs/soak/wasm-2m
mkdir -p "$OUT/plugins/wasm-filter"
cp docs/examples/plugin-wasm-filter/{plugin.toml,filter.wasm} "$OUT/plugins/wasm-filter/"
cat > "$OUT/plugins-v3-state.toml" <<'TOML'
version = 1

[plugins."dev.xtervo.wasm-filter"]
enabled = true
permissions_approved = true
permissions = ["terminal.output_filter"]
TOML
export XTERVO_PLUGINS="$OUT/plugins"
DURATION=2m SOAK_DISPLAY=:148 SOAK_OUT="$OUT" SOAK_NO_SHOTS=1 ./scripts/soak.sh
```

`report.md` / `samples.csv` / `summary.json` are generated by `scripts/soak.sh`;
`run.log` and `app.log` are the raw harness/app logs from this run.
