# Tervo UI / 视觉设计规范

> 状态：v1（2026-11-09）
> 适用范围：`crates/app/ui/main.slint`、Settings、TabBar、右键菜单、浮层、图标、动效、双语布局。
> 相关文档：`docs/RETEST_CHECKLIST.md`（人工验收）、`docs/SOAK.md`（性能/内存门禁）、`docs/FEATURE_MATRIX.md`（功能矩阵）。

## 0. 一句话原则

**终端是纸，界面是页边距。**

Tervo 的美学方向是“安静的工作台 / 排版良好的技术文档”，不是赛博朋克、玻璃拟态或仪表盘。所有视觉元素都必须回答三个问题：

1. 它帮助**识别**什么？
2. 它帮助**操作**什么？
3. 它帮助**反馈**什么？

回答不了就删掉。

---

## 1. 美学方向

### 1.1 内容优先

- 终端文字是第一视觉层；TabBar、状态栏、Settings 是低对比背景层。
- 不抢亮度：不用大面积渐变、发光、玻璃、重阴影。
- 不装饰性动画；动效只表达状态变化或因果关系。
- 空白是层级，不是浪费。

### 1.2 工具感高于展示感

- 用户是来工作的，不是来看 UI 的。
- 界面应该“可扫读、可预测、可恢复”，而不是“第一眼惊艳”。
- 常驻界面保持平面；只有浮层（菜单、旧版 Settings modal）允许阴影。

### 1.3 统一的“材料语言”

同一界面只使用一套：

```text
圆角：5 / 6 / 10 px
边框：1 px 低对比
阴影：仅浮层
表面：bg / surface / raise
```

不允许某个控件突然换成胶囊、发光边、粗阴影或另一种圆角。

## 2. 色板与语义

以 `Palette` 为唯一来源，不在组件里硬编码新颜色。

| Token | 用途 |
|---|---|
| `bg` | 终端/页面底色 |
| `surface` | 卡片、侧栏、次级表面 |
| `raise` | 浮层、输入框、按钮底 |
| `hover` | 悬停表面 |
| `border` | 1px 分隔/描边 |
| `text` | 主文字 |
| `subtext` | 分组标题、快捷键、说明 |
| `muted` | 更弱的提示 |
| `accent` | 当前选择/主操作，全屏最多一个强调色 |
| `danger` | 关闭/删除/破坏性操作 |
| `accent-text` | accent 底上的文字 |

约束：

- 背景用近黑/近白的中性色，目标是不刺眼；不追求纯黑纯白。
- 状态色只做淡底、细边或小图标，不做满屏高亮。
- 颜色不是唯一信息：Read Only / Broadcast 同时有文字或状态标记。
- 危险色只给破坏性动作；普通强调不使用 danger。

## 3. 排版

### 3.1 字体分工

```text
终端：等宽字体（可配置）
UI：无衬线字体
图标：Path/Shape 手绘，不依赖 emoji 字体
```

### 3.2 字号层级

| 字号 | 用途 |
|---:|---|
| 11 px | 辅助说明、快捷键、状态 |
| 12 px | 字段/按钮/菜单辅助 |
| 13 px | 分组标题、分区标签 |
| 14 px | 菜单项、设置正文 |
| 15 px | 页面正文、标题栏正文 |
| 17 px | Settings 页面主标题 |

规则：

- 不为了塞内容把标签缩到 9px 以下。
- 中文/英文共用同一网格；切换语言不跳版。
- 长文本 elide；不靠缩小字号硬塞。
- 菜单快捷键右对齐，避免和 label 混在一起。

## 4. 间距、尺寸与几何

| 项目 | 规范 |
|---|---|
| Settings 控件行高 | 26 px |
| 右键菜单行高 | 30 px |
| 分组标题行高 | 22 px |
| TabBar 高度 | 由 `tabbar-height` 统一 |
| 右键菜单宽度 | 280 px（窄窗可滚动） |
| 常规圆角 | 5 / 6 px |
| 浮层/卡片圆角 | 10 px |
| 图标 | 16 px，1.4 px 单色描边 |
| 菜单内左内边距 | 10 px |

布局约束：

- Settings 内容区**不设固定最大宽度**，必须随窗口放大；窗口变窄时优先滚动/换行，不裁操作。
- 菜单靠右/靠下时翻转到可视区域；窄窗滚动而不是溢出。
- 同一行的图标、文字、快捷键有固定列，不因 label 长度互相挤。

## 5. 图标原则

### 5.1 什么时候用图标

适合：

- 持久导航：Appearance / Terminal / Window / Keys / Profiles / Plugins / Vault / Advanced
- 固定状态：Pin、Read Only、Broadcast
- 明确工具：Settings 齿轮、搜索放大镜

不适合：

- 一次性动作列表（右键菜单）
- 纯装饰分类
- 用 emoji 代替 UI 图标
- 用模糊的“太阳/放射线”图形表示齿轮

### 5.2 规格

```text
16 px
1.4 px 单色描边
tint / active / danger 三态
不依赖彩色字体
```

- 图标永远不是唯一标签；导航图标旁必须有文字。
- 同一图形只表达一个含义。
- 图标必须在 16px 下可辨；Settings 齿轮必须是**连为一体的 8 齿 + 中心孔**。
- Pin 用 Path 画图钉，不依赖 emoji。
- 新图标必须用像素签名或截图回归，防止退化成太阳/搜索。

### 5.3 右键菜单：纯文字

终端右键菜单不使用图标：

```text
文字 + 分组标题 + 快捷键 + 危险色
```

理由：右键菜单是一次性动作列表，图标只会增加噪声，并和 Settings/导航图标混淆。

保留：

- 分组：Link / Clipboard / Pane / View / Session
- 30px 行高、280px 宽、窄窗滚动
- Read Only / Broadcast 的 active 底色
- Close 的 danger hover
- 悬停左侧 2px 标记

TabBar/Profile 菜单使用紧凑的 `MenuRow`，同样以文字为主。

## 6. Settings 设计

### 6.1 形态

- Settings 是窗口内的**持久 Tab**，不是一次性 modal。
- 点击终端 Tab / 内容区：只 suspend，不销毁。
- 只有 ×、Esc、齿轮才真正关闭。
- `TERVO_SETTINGS_LEGACY=1` 时退回居中 modal，仅作为兼容路径。

### 6.2 布局

```text
顶部：Settings 标题 + 搜索 + 关闭
左侧：分类导航（可滚动）
右侧：内容卡片（随窗口宽度变化）
```

- 内容区宽度必须跟随窗口，不设 980px 硬上限。
- 分类切换保留滚动位置/搜索状态的产品行为以现有实现为准。
- 搜索无结果时给出明确空状态，不显示空白卡片。

### 6.3 交互

- 改动即时预览；需要持久化的字段写回 config。
- 外部 config 热更新不覆盖正在编辑的临时表单。
- 修改失败必须有可见提示，不能静默丢。
- 表单错误贴近字段，不只弹全局红点。

---

## 7. 交互与动效

### 7.1 直接操作

- 滑块只有**左键按住拖动**才更新；悬停/划过不改值。
- 点击轨道可以跳转，但必须在按下后进入 dragging。
- 拖拽 Tab 超过阈值才进入拖拽态；显示 ghost、2px 插入线、其余 Tab 平滑让位。
- Esc / 窗口失焦取消拖拽并复位。
- 动画短、可取消；不做弹跳、呼吸、循环装饰。

### 7.2 动效预算

```text
hover/active     立即
菜单/面板出现     短过渡
Tab 让位          约 8px gap + animate
视觉铃            约 160ms
```

- 不在每帧路径做重布局/重分配。
- 动效不能阻塞 PTY 或输入。
- 未来支持系统 reduced motion 时，关闭非必要位移/闪烁。

### 7.3 Esc 层级

统一从最上层开始关闭：

```text
输入法组合中  → 归 IME，不写 PTY
拖拽中        → 取消拖拽
菜单/下拉     → 关闭菜单
搜索          → 关闭搜索
Settings      → 关闭 Settings
```

## 8. Tab 与 Pin

- Tab 标题优先，状态图标其次。
- pinned Tab 固定在左侧前缀区，显示小图钉，不抢标题。
- Pin/Unpin 是 additive 行为；旧 Tab 会话默认 `pinned=false`。
- 拖拽 ghost 是简化副本，不是完整控件；不重建 Tab 模型。
- pinned/unpinned 跨组拖拽非法：不亮插入线、不移动，避免“看起来能放”。
- 关闭/重命名/复制等原行为不受 Pin 影响。

---

## 9. 双语与排版

- 同一页面不能中英混排。
- 语言是全局选项：`Config.language = "en" | "zh"`，默认 `en`，未知值回退 `en`。
- Settings、右键菜单、TabBar 菜单、搜索索引/结果必须一起切换。
- 专有名词可保留：SFTP、Sixel、Kitty、JSON、URL。
- 语言选项自身必须同时显示 `English` / `中文`，这是唯一预期例外。
- 技术限制（当前）：
  - 插件名/描述属于第三方数据，可不翻译。
  - 少数 Rust 动态错误（Profile 校验、known_hosts、Vault 底层）仍需后续补齐。
- 切换语言后不得溢出、裁切、重叠。

---

## 10. 反馈、错误与空状态

- 成功反馈轻量、短暂，不用大色块。
- 错误说明“发生了什么 + 下一步”，不是只有红点。
- 危险操作靠位置 + 颜色 + hover 三重区分。
- 空状态给出下一步动作，不只显示空白。
- 状态栏只保留一行关键信息，详细内容进浮层/日志。

---

## 11. 性能也是设计

视觉设计不能以卡顿为代价：

- UI 主动拉帧，终端核心不推送整帧。
- 大输出只重绘 damage 区域。
- 图片/emoji/字体缓存必须有上限。
- 每个大型功能合并前必须做内存门禁：
  - 2m soak 必跑；
  - 触及终端/渲染/循环的功能跑 15m/30m；
  - 记录 RSS/PSS、线程/FD、live heap；
  - 不允许用改阈值或单纯 `malloc_trim` 掩盖生命周期问题。
- 详细方法见 `docs/SOAK.md`。

## 12. 反模式清单

看到以下模式应拒绝：

```text
□ 右键菜单塞装饰图标
□ 用太阳/放射线冒充齿轮
□ 一个功能一套新颜色/新字号
□ 滑块悬停就改值
□ Settings 点击终端就销毁
□ 设置内容固定 980px，不随窗口放大
□ 中英混排在同一个页面
□ 用 emoji 当 UI 图标
□ 动画弹跳/循环/阻塞输入
□ 为了过内存门禁改 soak 阈值
□ 用纯黑纯白硬拉对比
□ 图标是唯一标签、没有 tooltip/文字
```

## 13. 验收清单

### 视觉

- [ ] Settings 齿轮是 8 齿 + 中心孔，不是太阳/搜索
- [ ] 右键菜单无图标，文字和分组标题左对齐
- [ ] 菜单 280px、30px 行高、窄窗可滚动、右下翻转正常
- [ ] 卡片/按钮/输入框圆角、边框、阴影来自同一套 token
- [ ] 亮色/暗色主题都保持低饱和、可读
- [ ] 16px 图标不糊、不裁、不靠 emoji

### 交互

- [ ] 滑块只有左键拖动才变，悬停 0 像素变化
- [ ] Tab 拖拽有 ghost/插入线/让位；Esc 取消复位
- [ ] pinned 跨组拖拽不亮线、不移动
- [ ] Settings 切到终端只 suspend，×/Esc/齿轮才关闭
- [ ] Esc 层级正确，IME 组合期间不写 PTY

### 双语

- [ ] en 页无中文（语言选项自身除外）
- [ ] zh 页无未翻译整句
- [ ] 右键菜单、TabBar 菜单、搜索一起切换
- [ ] 语言切换不溢出、不重叠
- [ ] 重启后语言持久化

### 性能

- [ ] 2m soak PASS，RSS/线程/FD 无异常
- [ ] 大型功能有 15m/30m 数据
- [ ] 没有用阈值/trim 掩盖泄漏

## 15. 内联图片与背景图

- Sixel/IIP 超出 pane 时只缩小、不放大；保持原图用于灯箱。
- 点击内联图片打开灯箱；提供 −/＋/Fit/Close，Esc 关闭；灯箱不改变终端选区。
- 背景图字段支持 `~` 和 Browse；无图时 opacity 通过透明窗口生效，依赖桌面合成器。
- 图片是终端内容，不应把 TabBar/设置面板一起透明化。
