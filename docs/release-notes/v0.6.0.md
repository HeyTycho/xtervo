# xtervo 0.6.0

第一个公开版本。xtervo 是用 Rust + Slint 写的 Linux 原生终端模拟器，
目标是把日常终端做得顺滑、快、轻：低内存、低输入延迟、可脚本化控制。

本项目完全由 **DeepSeek + DeepSeek Harness** 完成（代码、测试与文档）。
交互和产品取舍参考过 Tabby 等现代终端，但不追求替代、像素级复刻或插件兼容。

## 亮点

**终端核心**
- VT220 / xterm 兼容：宽字符与 CJK、emoji ZWJ、组合字符、24 位色、备用屏、
  鼠标上报（1000/1002/1003/1006）
- 内联图片：Sixel、iTerm2 IIP、Kitty graphics（源裁剪、placement、z-order）
- 查找（大小写/正则）、双击选词/三击选行、bracketed paste、URL/文件路径点击
- kitty keyboard protocol、多段快捷键、IME 候选框跟随真实光标

**工作区**
- 标签页 + 分屏（拖拽重排、放大、双击手柄最大化）、命名工作区、多窗口
- 命令面板、设置页、侧栏、状态 pill、会话恢复

**连接与插件**（可选，不装也能当纯本地终端）
- 本地 shell / SSH / Serial / Telnet Profile
- native SSH：russh、ProxyJump、端口转发、known_hosts 预检、Vault passphrase
- SFTP 队列、Vault、插件 API v3（process JSON-RPC）、MCP、AI panel

**可靠性**
- 原子会话快照 + `.bak` 回退、异常退出检测、safe mode
- 2m/15m/30m soak 内存门禁；发布包带 SHA256

## 安装

从 GitHub Releases 下载：

```bash
# tar.gz
tar xzf xtervo-0.6.0-linux-x86_64.tar.gz
cd xtervo-0.6.0-linux-x86_64
./install.sh --prefix ~/.local

# 或 .deb
sudo dpkg -i xtervo_0.6.0-1_amd64.deb
```

校验：

```bash
sha256sum -c --ignore-missing SHA256SUMS
```

从源码构建需要 Rust 1.85+ 与 X11 开发库，见 README 的“从源码构建”。

## 测试范围

目前只在 **Ubuntu 22.04 / 24.04** 实机测试；其他发行版/桌面未验证。
Wayland 目前通过 XWayland 运行；真实 Wayland + fcitx5/RIME 的反馈尤其欢迎。

## 已知限制

见 [README 的已知限制](../../README.md#已知限制)。
重点：原生 Wayland 的剪贴板/DnD/全局热键受限；插件没有 OS 级沙箱；
自动更新/崩溃上报尚未实现。
