# 内部过程记录（不是用户文档）

> **这里不是用户文档。** 本目录保存开发过程中的开工单、夜班进度、任务看板、行动清单和
> review backlog，只用于保留当时的决策、证据与排期上下文。

- 这些文件是**时间点快照**：编号、状态、“下一步”都可能已经过期，不要当作当前事实。
- 当前主线事实以 [`../MAINLINE_STATUS.md`](../MAINLINE_STATUS.md) 为准；逐条能力状态以
  [`../FEATURE_MATRIX.md`](../FEATURE_MATRIX.md) 与 [`../CLOSURE.md`](../CLOSURE.md) 为准；
  版本变更以 [`../../CHANGELOG.md`](../../CHANGELOG.md) 和 `git log` 为准。
- 面向用户的文档放在 `docs/` 顶层，并通过 [`../README.md`](../README.md) 索引。
- 新一轮的过程记录可以继续放进本目录；如果是长期有效的设计/使用文档，请放到 `docs/`
  顶层并在索引里登记。
